# 강사용 진행안 — 가짜 주식시장 만들기 (3시간+2시간 권장, 5시간 압축 가능)

## 운영 원칙

- 시뮬레이션이 처음인 참가자는 입장 직후 `guide.html`의 10분 개념 가이드를 읽게 한다. 사전 읽기가 어려우면 본 세션 시작 전 10분을 별도로 잡고, 활동 시간 300분에는 포함하지 않는다.
- 개념 가이드를 읽은 뒤에도 공식을 재현하게 하지 않는다. 참가자가 “무엇을 고정했고, 무엇을 바꿨고, 한 번의 결과인지 반복 결과인지”를 말할 수 있으면 충분하다.
- 3~4명 한 팀, 조당 노트북 한 대, 역할 순환(질문 설계 / 조작 / 검증 / 기록).
- 모든 활동은 **예상 → 실행 → 비교 → 가정 하나 변경**. 예상을 적기 전에는 실행 버튼을 누르지 않게 한다.
- 판별 라운드는 선택한 답의 확률과 함께한다. 나머지 확률은 두 후보에 균등 배분한다. "틀린 것보다 확신하고 틀린 것이 문제"를 하루 종일 반복한다.
- 개인 강사 노트북: `facilitate.html`(활동·타이머·프로젝터·접속 현황·라운드 공개). 상세 답안과 초기화는 `instructor.html`에서 확인한다.
- 강의실 Windows 프로젝터: `present.html?class=수업코드`를 열고 F11 전체화면. 강사 화면을 미러링하지 않는다.
- 참가자: `join.html?class=수업코드`로 입장한다. 프로젝터에는 강사 정보·팀별 답안·관리 버튼이 표시되지 않는다.
- R3는 **강사가 열기 전까지 수업 화면에서 잠금**. 공개 저장소의 데이터이므로 보안 시험용 장치라고 표현하지 않는다.

## 권장 운영: 이틀(3h+2h)

- 1일차 180분: 0교시(20) → 1교시(55) → 휴식(10) → 2교시(60) → 설명서 v1(20) → 과제 안내(15). 과제: 본인 업무 시계열(공개 지수만)로 2a 검사표 돌려 오기.
- 2일차 120분: 리캡·R2 리더보드(10) → 3교시(55) → 휴식(10) → 4교시(30, 브리핑 축약) → 5교시(15).

## 리허설 체크리스트

- [ ] 첫 참가자 동선이 `index.html` → `guide.html` → `join.html` 또는 첫 활동으로 자연스럽게 이어지는지.
- [ ] 강사 노트북의 `facilitate.html`과 Windows PC의 `present.html`이 같은 수업 코드인지, 활동 전환과 타이머가 4초 안에 반영되는지.
- [ ] 각 활동 상단의 “시뮬레이션이 처음이라면” 설명과 개념 링크가 해당 활동의 용어를 실제로 설명하는지.
- [ ] `npm test` 통과, 개발 서버 또는 배포본에서 join → R1 제출 → 강사 공개 → 리더보드가 3초 안에 갱신되는지.
- [ ] R3가 잠금 상태로 시작하는지(강사 콘솔에 "마감"으로 표시). 이것이 보안 통제가 아니라는 점을 강사가 알고 있는지.
- [ ] 프로젝터에서 로그축·한글·범례가 읽히는지. 라이트/다크 모드 둘 다 확인.
- [ ] 경매 페이지에서 무거래·체결·동률을 각 한 번, 규칙 저장 후 3c에서 불러오는지. Game of Life 글라이더가 4세대 뒤 대각선 이동하는지.
- [ ] 강사 비밀번호와 수업 코드(기본 MESA)를 정하고 참가자 안내문에 적었는지.
- [ ] 실제 데이터 출처·이용조건·해시(`index.html` 하단)를 확인했는지.
- [ ] 백업: 서버 연결 실패 메시지가 표시된 경우에만 나타나는 "오프라인 공개"와 R3 "오프라인 잠금 해제"를 강사가 누른다.
