# 교육용 단일가 경매 규칙

팀별 초기 현금 1,000, 주식 10주, 직전 가격 100, 호가단위 1. 한 라운드에 팀별 매수·매도·관망 하나만 제출하며 수량은 1주다. 수정하면 미체결 기존 주문을 대체한다.

1. 제출 지정가와 직전 가격을 후보가격으로 둔다.
2. 후보 `p`에서 `D(p)`는 지정가 ≥ p인 매수 주문 수, `S(p)`는 지정가 ≤ p인 매도 주문 수다.
3. `min(D,S)` 최대 → `|D−S|` 최소 → 직전 가격과 거리 최소 → 더 낮은 가격 순으로 고른다.
4. 최대 체결량이 0이면 무거래이며 직전 가격을 유지한다.
5. 매수는 높은 지정가, 매도는 낮은 지정가 우선이다. 같은 지정가는 접수 순서다.
6. 정해진 수량만 선정 단일 가격으로 체결한다. 잔여 주문은 라운드 종료 때 만료한다.

이 tie-break는 교육용 규칙이다. 실제 거래소 제도의 완전한 복제품이 아니다. 공매도, 음수 현금, 자기 거래, 자동 실거래를 허용하지 않는다. 같은 엔진(`site/assets/js/auction.js`)을 3c의 에이전트 시장도 사용한다 — 다만 에이전트 시장은 시작가 1,000, 에이전트당 주식 10주·같은 값의 현금이다.
